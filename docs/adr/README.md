# Architecture Decision Records (ADRs)

This directory documents the key architectural choices, technical decisions, and trade-offs made across the `Adda` platform.

For more details on the ADR process and format, see [ADR-0000](0000-record-architecture-decisions.md).

## Creating a New ADR

1. Use the format established in [ADR-0000](0000-record-architecture-decisions.md).
2. Assign the next sequential four-digit number (e.g. `0002-<topic>.md`).
3. Detail the Context, Decision, Alternatives Considered, and Consequences.
4. Add the new record to the index table above.
5. If the new ADR supersedes a prior decision, mark the previous record's status as `Superseded by ADR-XXXX`.
